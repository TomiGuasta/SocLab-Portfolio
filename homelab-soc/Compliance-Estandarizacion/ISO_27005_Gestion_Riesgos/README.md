# ISO 27005 - Gestión de Riesgos

Este directorio contiene la documentación y las evaluaciones de riesgos alineadas con la norma ISO/IEC 27005.

## Objetivo
Establecer un proceso sistemático para la evaluación y tratamiento de riesgos de seguridad de la información, utilizando los escenarios de ataque y las medidas de defensa documentadas en este portfolio.

## Estructura Propuesta
- `Metodologia.md`: Descripción de la metodología de evaluación de riesgos adoptada.
- `Registro_Riesgos.md`: Registro centralizado de riesgos identificados.
- `Evaluaciones/`: Evaluaciones detalladas de riesgos por área o ataque.
- `Tratamiento/`: Planes de tratamiento de riesgos.
