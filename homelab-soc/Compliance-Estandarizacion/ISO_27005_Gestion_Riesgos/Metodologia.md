# Metodología de Gestión de Riesgos (ISO 27005)

Esta metodología define el enfoque para identificar, analizar y evaluar los riesgos en el laboratorio.

## Escala de Evaluación

Utilizaremos una matriz cualitativa (o semicuantitativa) de 3x3 o 5x5.

### Probabilidad (Likelihood)
1. Muy Baja
2. Baja
3. Media
4. Alta
5. Muy Alta

### Impacto (Impact)
1. Bajo
2. Medio
3. Alto
4. Muy Alto

## Cálculo del Riesgo
`Riesgo = Probabilidad * Impacto`

*   **Bajo (1-4):** Riesgo aceptable.
*   **Medio (5-9):** Requiere monitoreo.
*   **Alto (10-20):** Requiere plan de tratamiento.
