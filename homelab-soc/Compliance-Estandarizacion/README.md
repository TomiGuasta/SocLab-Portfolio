# Compliance y Estandarización ISO

Este directorio centraliza la integración de marcos de trabajo ISO (27001, 27002, 27005) para alinear el laboratorio técnico con estándares internacionales de ciberseguridad.

## Estructura y Navegación

- [ISO 27001 - Gobernanza](./ISO_27001_Gobernanza/): Define el contexto, alcance, políticas y objetivos del sistema de gestión (SGSI) aplicado al laboratorio.
- [ISO 27002 - Controles](./ISO_27002_Controles/): Catálogo de controles técnicos mapeados a los laboratorios y playbooks existentes.
- [ISO 27005 - Gestión de Riesgos](./ISO_27005_Gestion_Riesgos/): Metodología y registro de riesgos que justifica las pruebas y defensas implementadas.
