# Detecciones

Cada archivo en esta carpeta corresponde a una query SPL usada para detectar un tipo de ataque específico, junto con su documentación (qué detecta, parámetros, y un resultado de ejemplo obtenido en el lab).

## Convención de nombres

`<tipo-ataque>-<variante>.md`

Ejemplos: `ssh-bruteforce-attempt.md`, `ssh-bruteforce-success.md`, `port-scan-nmap.md`
