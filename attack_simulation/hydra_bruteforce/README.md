# Hydra Telnet Brute Force Attack Simulation

Simulación de ataque de BruteForce utilizando Hydra contra un servicio Telnet y SSH vulnerable dentro de un laboratorio local y controlado (MV MetaSploitable 2).

## Objetivo

- Simular un credential attack.
- Analizar evidencia generada.
- Revisar logs de autenticación.
- Documentar oportunidades de detección.

## Infraestructura

Attacker: Kali Linux

Target: Metasploitable 2

Network: VirtualBox Host-Only

## Herramienta utilizada

Hydra
